# 펄스케어 (가칭) — 스마트워치 건강 코칭 앱

어떤 워치든 그 데이터를 매일 아침 한국어 컨디션 점수와 "오늘 할 일 하나"로 바꾸고, 멀리 사는 가족이 함께 챙길 수 있게 하는 앱입니다.
기획서: 펄스케어 기획서 (Claude Docs). 섹션 번호(13번 등)는 기획서 번호입니다.

국내 스마트폰의 81%가 갤럭시라 **Android + Wear OS를 먼저** 만들고, iPhone + Apple Watch는 같은 로직으로 뒤따릅니다.

| `mobile` | 폰 앱 (Compose). | `core/history` · `mobile` 기록 탭 | 아래 탭 "오늘 · 기록". 주간(7일)·월간(30일) 컨디션 점수 막대(학습 중·추정은 옅게), 수면 시간·HRV·안정시 심박 추이와 내 평소 범위 띠(최근 28일 중앙값 ± 1σ), 평균 취침과 평소 비교, 미션 달력(직접 완료 / 워치로 확인 / 못 한 날, 주 5일이면 배지), 지난 기간 대비 한 줄. 날짜를 누르면 그날 점수·이유·수면·회복·미션·세부 점수. 건강 수치는 저장하지 않고 열 때마다 Health Connect에서 읽으며, 앱을 열지 않은 날 점수는 같은 엔진으로 다시 계산 |

## 빌드와 테스트

```
cd android
./gradlew :core:test                    # 로직만 (Android SDK 불필요)
./gradlew :mobile:testDebugUnitTest     # 폰 앱 로직 + 화면 렌더링
./gradlew :mobile:assembleDebug         # 테스트 APK (CI Artifacts에도 pulsecare-debug-apk로 올라감)
./gradlew :mobile:recordPaparazziDebug  # 화면 이미지 → mobile/src/test/snapshots/images
./gradlew :wear:assembleDebug           # 워치 APK (같은 패키지 이름: 폰 앱과 같은 서명이어야 연결됨)
./gradlew :wear:recordPaparazziDebug    # 워치 화면 이미지
PULSECARE_TEST_DB=jdbc:postgresql://localhost:5432/pulsecare_test?user=postgres ./gradlew :server:test
```

요구사항: JDK 17+, 폰 앱은 Android SDK 36. 휴대폰 Android 8+ (Health Connect 필요: Android 14+는 기본 내장, 13 이하는 앱 설치).
갤럭시 워치는 삼성 헬스 설정에서 Health Connect 동기화를 켜야 기록이 들어옵니다.

## 컨디션 점수 요약

| 영역 | 지표 | 가중치 |
|---|---|---|
| 수면 35% | 수면 시간 (필요량 대비) · 수면 질 (효율, 깊은 잠) · 규칙성 (7일 취침 시각 편차) | 15 · 10 · 10 |
| 회복 40% | HRV · 안정시 심박 (기준선 대비) | 25 · 15 |
| 활동 부하 15% | 7일 평균 ÷ 28일 평균 | 15 |
| 보조 10% | 피부 온도 · 호흡수 (지원 기기만) | 5 · 5 |

- 생체 신호: `z = (x − 중앙값) / (1.4826 · MAD)`, `s = 100 / (1 + e^−(1.2·d·z + 0.85))` → 평소 70, +1σ 89, −1σ 41
- 행동 지표도 평소 = 70: 수면 질·규칙성은 같은 식으로 내 기준선과 비교, 수면 시간은 필요량을 채우면 70 (120%에서 100), 활동 부하는 0.8~1.3배가 70이고 70을 넘지 않음
- 측정되지 않은 지표는 빼고 남은 가중치로 다시 나눕니다
- 상한: 수면 4시간 미만 50, 아픔 태그 50, 주의 신호 60, 회복 지표가 모두 없으면 80

기획서에 없어 코드에서 정한 세부 규칙은 `ConditionScoreEngine.kt` 주석에 적었습니다 (MAD 하한, 활동 부하 0.6 미만 처리, 깊은 잠 감점 기울기 등).
