# 실기기 테스트 안내

갤럭시 폰 + 갤럭시 워치로 펄스케어 테스트 빌드를 확인하는 순서입니다. 테스트 빌드에는 **내 정보 > 테스트 도구**가 있어서, 정해진 시각을 기다리지 않고 알림을 보내 보고 Health Connect에 무엇이 들어왔는지 볼 수 있습니다.

## 0. 준비물

- Android 8 이상 폰 (Android 14 이상 권장: Health Connect가 기본 내장이고 백그라운드 읽기를 지원)
- 갤럭시 워치를 차고 **하룻밤 이상** 잔 기록 (점수는 7일 기록이 쌓여야 정식으로 나옵니다. 그 전에는 "학습 중" 홈)
- 테스트 APK: `mobile-debug.apk`
  - GitHub > Actions > PulseCare > 최근 실행 > Artifacts > `pulsecare-debug-apk`
  - 또는 직접 빌드: `cd android && ./gradlew :mobile:assembleDebug` → `mobile/build/outputs/apk/debug/mobile-debug.apk`

## 1. 설치

**폰에서 바로**: APK를 폰으로 옮겨 열고 "출처를 알 수 없는 앱 설치"를 허용합니다.

**PC에서 adb로**: 폰의 개발자 옵션 > USB 디버깅을 켜고

```
adb install -r mobile-debug.apk
```

## 2. 워치 기록을 Health Connect로 보내기

1. Android 13 이하면 Play 스토어에서 **Health Connect** 설치
2. **삼성 헬스 > 설정 > Health Connect** (또는 "데이터 공유")에서 수면·심박·걸음 등 쓰기를 허용
3. 삼성 헬스를 한 번 열어 동기화 (아침에 일어나서 삼성 헬스를 열어야 어젯밤 수면이 넘어오는 경우가 많습니다)

## 3. 첫 실행

1. 이용 동의 필수 4개(+ 선택: 이용 통계) 체크("보기"는 웹 문서, `main`에 합치기 전에는 열리지 않음) → 목표 고르기 → **Health Connect 연결** → 권한 모두 허용
2. 알림 권한 허용 (Android 13+)
3. 백그라운드 읽기("앱을 사용하지 않을 때 데이터 읽기") 허용. 꺼져 있으면 아침 알림이 점수 없이 갑니다

확인할 것:
- [ ] 홈이 뜨고 "N일째" 또는 점수가 보인다
- [ ] 권한을 일부 거부하면 홈 위에 배너가 보인다

## 4. 테스트 도구로 첫날 확인

**내 정보 > 테스트 도구 (테스트 빌드) > 데이터·알림 점검**

| 항목 | 정상 | 아니면 |
|---|---|---|
| Health Connect | 사용 가능 | Health Connect 설치·업데이트 |
| 백그라운드 읽기 권한 | 허용 | Health Connect 앱 > 앱 권한 > 펄스케어 |
| 알림 권한 | 허용 | 폰 설정 > 앱 > 펄스케어 > 알림 |
| 다음 아침 리포트 / 저녁 요약 | 내일(또는 오늘) 시각 | 앱을 한 번 닫았다 다시 열기 |
| 지난 30일 기록 — 수면·HRV·걸음 | 개수와 출처 "삼성 헬스" | 2번 동기화 설정 확인 |

"오늘 계산"에서 점수, 이유, 하위 점수, 오늘의 미션과 확인 상태를 볼 수 있습니다.

**지금 실행해 보기** (각각 눌러 보고 알림을 확인):
- [ ] 아침 리포트 보내기 → "오늘의 컨디션" 알림. 화면을 잠그면 점수 없이 "오늘의 컨디션이 준비됐어요"만 보인다
- [ ] 저녁 요약 보내기 → 미션을 안 했으면 "내일 다시 해볼까요?" 알림과 **내일 다시 / 다른 미션으로** 버튼
- [ ] 저녁 알림에서 "내일 다시" → 다음 날 홈 미션이 같은 미션
- [ ] 주간 리포트 만들기 → 주간 리포트 알림, 홈에 주간 카드

## 5. 설정 바꾸기

**내 정보 > 알림**
- [ ] 아침 시각을 지금부터 2~3분 뒤로 바꾸면 테스트 도구의 "다음 아침 리포트"가 바뀌고, 그 시각 즈음 알림이 온다 (WorkManager라 몇 분 늦을 수 있음)
- [ ] 아침 알림을 끄면 "다음 아침 리포트"가 "예약 없음"
- [ ] 쉽게 보기를 켜면 글자가 커지고 "다른 미션" 버튼이 사라진다

## 6. 워치 앱 (갤럭시 워치, Wear OS 3+)

워치 APK는 `wear-debug.apk`(같은 Actions Artifacts 안)입니다. **폰 APK와 같은 빌드에서 나온 것**이어야 서로 연결됩니다(서명이 같아야 함).

설치: 워치의 설정 > 개발자 옵션 > ADB 디버깅과 Wi-Fi 디버깅을 켜고

```
adb connect <워치 IP>:<포트>      # 워치 화면의 "무선 디버깅"에 나오는 주소 (먼저 adb pair)
adb -s <워치 IP>:<포트> install -r wear-debug.apk
```

- [ ] 폰에서 펄스케어 홈을 한 번 열면 워치 앱에 같은 점수·미션이 보인다
- [ ] 워치에서 "미션 완료" → 폰 홈을 다시 열면 미션이 완료로 바뀐다
- [ ] 타일 추가(워치 화면 오른쪽 끝 > 타일 추가 > 펄스케어): 점수와 미션이 보이고 누르면 앱이 열린다
- [ ] 워치 페이스 편집 > 컴플리케이션에서 "컨디션 점수"를 고르면 점수가 보인다
- [ ] SOS 도움 요청 → 5초 안에 취소하면 아무것도 가지 않는다
- [ ] SOS를 취소하지 않으면 폰에 "워치에서 SOS를 눌렀어요" 알림과 "119 연결" 버튼 (보호자에게는 아직 가지 않음)
- [ ] 다음 날 아침 리포트 전에는 워치에 "어제 기록"이 보이고, 리포트 뒤 바뀐다

## 6-1. 알림 응답

주의 알림이 실제로 올 때(또는 홈 카드에서):

- [ ] 알림의 "괜찮아요" / "잘못된 알림이에요"를 누르면 알림이 사라지고, 홈 카드에 "고마워요"가 보인다
- [ ] 응답한 신호는 다음 날 아침까지 같은 값이면 다시 오지 않는다 (더 나빠지면 온다)
- [ ] 같은 신호를 2주 안에 두 번 "잘못된 알림"이라고 하면 홈 카드에 "7일 쉬기" 제안 → 쉬기를 누르면 그 기간 알림이 오지 않고, "다시 받기"로 되돌릴 수 있다
- [ ] 알림이 틀렸다면 어떤 신호였고 그날 몸 상태가 어땠는지 함께 알려 주세요 (기준값을 고치는 데 써요)

## 6-2. 진료용 요약 PDF

- [ ] 기록 탭 > "진료용 요약 PDF" > 최근 30일 > PDF 만들고 보내기 → 공유 시트가 열리고, 카카오톡·메일·드라이브로 보낼 수 있다
- [ ] PDF를 열어 보면 두 장이고, 수면·심박·HRV·걸음 수치가 삼성 헬스 앱과 비슷하다 (다르면 어떤 항목인지 알려 주세요)
- [ ] 오늘 미션이 "한 달 건강 요약을 진료 때 공유"면 PDF를 보낸 뒤 완료가 된다

## 7. 가족 연결 (서버를 배포하고 서버 주소·Firebase 값을 넣어 빌드한 APK에서만)

테스트 도구의 "가족 서버" 칸에서 서버·푸시 설정이 "있음"인지 먼저 봅니다. 폰 두 대(보호자, 부모님)가 필요합니다.

- [ ] 두 폰 모두 가족 탭 > 이름 입력 > 시작하기
- [ ] 보호자 폰: "부모님 초대" → 코드를 메시지로 보내기 → 부모님 폰: 코드 입력 → 공유 동의 → 연결
- [ ] 부모님 폰에서 아침 리포트(테스트 도구 "아침 리포트 보내기") 뒤, 보호자 폰 가족 탭에 점수·미션이 보인다
- [ ] 부모님 워치 SOS → 5초 뒤 워치에 "보호자 1명에게 알렸어요", 보호자 폰에 긴급 알림(잠금화면에는 "[긴급] 확인이 필요한 알림이 있어요")
- [ ] 보호자 알림의 "확인했어요" → 부모님 폰에 "○○님이 확인했어요"
- [ ] 다시 SOS 후 부모님 폰 알림의 "취소하기" → 보호자 폰에 "괜찮다고 했어요"
- [ ] 보호자가 2명이면 1분 뒤 2순위에게, 3분 뒤 모두에게 다시 (Cloud Scheduler 1분 간격이라 최대 1분 늦을 수 있음)
- [ ] 저녁 8시 이후 보호자 폰에 "○○ 오늘 하루" 요약

## 8. 며칠 두고 볼 것

| 언제 | 확인 |
|---|---|
| 매일 아침 | 설정 시각에 아침 알림이 온다. 워치 기록이 늦으면 3시간 안에 다시 확인해 보낸다 |
| 걷기 미션 날 저녁 | 걸음 수를 채우면 미션이 자동으로 "완료"가 된다 (앱을 열거나 저녁 요약 시점) |
| 취침 미션 다음 날 | 어젯밤 수면 기록으로 취침 미션이 자동 확인된다 |
| 1~7일째 | "학습 중 N일째" → 8일째부터 정식 점수 |
| 일요일 21:00 | 주간 리포트 알림과 홈 주간 카드 |

## 9. 알려 주실 것

문제가 있으면 아래를 보내 주세요.

1. 폰·워치 모델, Android / Wear OS 버전
2. 테스트 도구 화면 캡처 (상태, 지난 30일 기록, 오늘 계산)
3. 받은 알림 캡처 (잠금화면 포함)
4. 예상과 달랐던 점: 점수가 컨디션과 안 맞음, 알림이 안 옴/늦게 옴, 미션 자동 확인이 안 됨 등
5. 가능하면 로그: `adb logcat -d | grep -iE "pulsecare|Worker|HealthConnect" > log.txt`
